# Tracy fork of deepseek-harness — the ledger

This repository (`TracyHQ/tch-vendor-deepseek-harness`) is Tracy's fork of upstream
[`deepseek-ai/deepseek-harness`](https://github.com/deepseek-ai/deepseek-harness). TCH mounts it as the submodule
`vendor/tracy/deepseek-harness`. Read this file before merging a new upstream release or cutting a `-tracy.N`: it lists
what Tracy carries on top of upstream (part 2) and what Tracy relies on in upstream without changing it (part 3). Both
lists are exactly what a merge can break in silence.

- **Upstream base:** tag `dsh-v0.2.0-rc.2` (merged 01/10/2026 on `chore/upgrade-dsh-0.2.0-rc.2`, fork PR #25; the
  `0.1.7-rc.2` line up to `-tracy.20` merged into it 04/10/2026, TCH `tasks/todo-dsh-core-0-2-0.md`). Before that: `dsh-v0.1.7-rc.2` (26/09/2026, `9c2251d2a5`).
- **Current Tracy version:** `0.2.0-rc.2-tracy.49` on the integration branch (TCH `fix/akemi-ja-boxing-followups`): tracy.48 plus dollar amounts kept out of inline math (part 2, "Dollar amounts stay text"). `0.2.0-rc.2-tracy.48` (fork PR #58, TCH `feat/right-panel-width`): tracy.47 plus the 300px Conversation default (part 2, "Narrow Conversation default"). `0.2.0-rc.2-tracy.47`: tracy.46 plus the composer keeping input-method text typed right after its own Backspace (13/10/2026). tracy.46 reunited the two lines (13/10/2026). It carries the integration line (tracy.41 narrow frame, tracy.42 answer actions, the Thinking label through fork PR #53) and the feedback cut `-tracy.45` (fork PR #55, on the `-tracy.43` hotfix line `fix/tracy-thinking-label`). `-tracy.44` was reserved and never cut; tracy.28/.29 were cut on branches that never merged (fork PR #39 before its rebase, and an earlier cut of `fix/tab-max-width`). TCH `develop` ran `-tracy.43`/`.45` without .41/.42 from #1244 until this cut: the next cut is `-tracy.47`, on this branch only.
- **Integration branch:** `chore/upgrade-dsh-0.2.0-rc.2` since the 0.2.0 upgrade (fork PRs #34–#37 base on it; `feat/tracy-sidebar-launcher` stopped at `-tracy.20`). Every Tracy PR bases on it; TCH points at the MERGE commit of
  the latest PR. `master` mirrors an old upstream and is not Tracy's line; `tracy-0.1.7` stopped at `-tracy.1`.

## 1. How to change the fork

One change (no registry since TCH ADR 0014):

1. In the submodule of a TCH worktree: `git checkout -b feat/tracy-<slug> <TCH develop's pointer>`.
2. Edit. `CI=true corepack pnpm install --ignore-scripts --frozen-lockfile` **inside the submodule** before vitest — a
   root TCH install relinks React and every client spec fails with `Cannot read properties of null (reading 'use…')`.
3. `./node_modules/.bin/vitest run <package>`; compare failures and `tsc` error counts against the untouched tree
   (`git stash`), never against zero.
4. `./node_modules/.bin/tsx scripts/release/bump.ts --family dsh 0.1.7-rc.2-tracy.N` (commits `release(dsh): …`).
5. Push, `gh pr create --base feat/tracy-sidebar-launcher`, merge. Upstream workflows that cannot run on the fork stay
   red on every PR (Dependency layout, Pack npm tarballs, node 22/24/26, e2e, Issue policy); they are not a signal.
6. In TCH: `git -C vendor/tracy/deepseek-harness checkout <merge commit>`, update the root `package.json`
   `description` to `tracy.N`. `pnpm-lock.yaml` does not change (workspace members record no version).

Merging a new upstream release: merge the upstream tag into the integration branch, re-carry every row of part 2,
walk every row of part 3, then run TCH's `presets`, `image-profile` and `boot-graph` gates — preset and cordis rows move
between releases (0.2.0-rc.1 moved `time-context`/`schedule` out of the web-app bundle and added `ui-settings-session-log`,
`product-analytics`, `otel`).

The `dsh-v0.2.0-rc.2` merge, measured (01/10 and 04/10/2026): 1638 upstream files; every part 3 name still present
(18 slots, 12 registration ids, 5 attributes, 43 hashed classes; the hash pattern `[hash]_[local]` is unchanged); 9 of
the 37 Tracy commits conflicted for real, 5 of them in the three `ui-sidebar-right` files upstream rewrote (launcher,
`keepLast`, preferred width). Rules that held: a `package.json` conflict takes the `0.2.0` side (316 of 317 were the
version field; `tool-todo` keeps its `@deepseek-ai/dsh-llm` dependency); `tool-ask-user` keeps Tracy's `recommended` /
`action` / `note` on the **legacy** tool only — upstream's default `setup()` in its spec builds the `timed` tool, so
Tracy's four cases there call `setup({ mode: 'legacy' })`; `ui-theme` keeps Tracy's `let preference` / `let fontSize`
localStorage boot script with upstream's 10–22 px range. Upstream flipped the chat defaults to `detailed`
(`ui-chat/src/chat-settings.ts`) — the Chat defaults row is re-applied, not dropped. New upstream rows `otel`,
`product-analytics`, `desktop-product-telemetry`, `ui-settings-session-log`, `session-telemetry-otel` are off in every
Tracy profile (TCH `check-image-profile` asserts it); `time-context` / `schedule` left the web-app bundle, so TCH's
patch lines for them are gone too.
